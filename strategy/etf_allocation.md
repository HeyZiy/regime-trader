# ETF 长期配置策略

> 主账户压舱石。默认只出观察报告；`--execute` 模式（每周一 9:35 定时）真实调仓。

---

## 一、定位

主账户压舱石，长线配置。资金占比即总占比。

**职责**：

| 钱   | 动作         | 依据                         |
|------|--------------|------------------------------|
| 基准 | 持有         | 有知有行（见第二节）         |
| 旧钱 | 阈值再平衡   | 偏离阈值触发，机械执行       |
| 新钱 | 节奏判断 | 全局节奏（双向极端档）+ 逐标的加速/正常/不急（趋势 x 估值），缺口自行补入 |

## 二、核心仓中性基准（有知有行）

> [有知有行长钱账户](https://youzhiyouxing.cn/advisor/longterm_strategy/)：
> 1. 配置大类资产，聪明地分散风险，适合当下的大类资产配置比例
> 2. 跟随波动调节资产比例。大类资产分散是影响收益的核心因素。中低估区间多配置股票，高估区间少配置股票。投入无需择时，每一笔买入都是当下的优选方案。
> 3. 分散配置多元品种 。对于股票类资产，长钱账户不会押注单一方向，而是以宽基指数为主、行业主题指数为辅，大盘股为主、中小盘股为辅，同时分散配置价值、均衡、成长风格。
> 4. 长期持有，胜率更大。短期收益无法预测，立足于更稳定和可预期的资产长期表现，更可能获得合理的投资收益。

定义在 `src/etf/config.py`（`CORE_BASELINE`）。

| 类别                 | ETF             | 当前配比 |
|----------------------|-----------------|----------|
| A 股宽基             | A500ETF         | 17%      |
| A 股宽基             | 中证1000增强ETF | 1%       |
| A 股宽基             | 红利ETF         | 14%      |
| 海外（额外增加）     | 纳指ETF         | 5%       |
| 海外（额外增加）     | 标普500ETF      | 5%       |
| 海外                 | 恒生科技ETF     | 10%      |
| 行业/主题            | 医药ETF         | 4%       |
| 行业/主题            | 养老ETF         | 2%       |
| 行业/主题            | 消费ETF         | 8%       |
| 黄金（额外增加）     | 黄金ETF         | 5%       |
| 现金（以及其他账户） | 现金/逆回购     | 29%      |

### 基准来源三规矩

1. **只抄基准，不抄择时**。基准配比里的估值观点（红利超配、行业倾斜等）归有知有行，本系统不再叠加自己的估值择时层——同一信息源用两次等于重复计价。动态侧只保留趋势信息（再平衡阈值松紧，见第四节）。
2. **适配只允许结构性增补，不做逐项主观调整**。当前适配 = 海外（纳指+标普）与黄金的结构性加入，属一次性决策；此后不逐项"看好谁多配点"。要调风险预算，只动"权益 vs 现金"的整体比例。
3. **人工对齐**。diff 有知有行最新基准与本表，有变化则同步改 `CORE_BASELINE` 与本表，同一提交内完成。抄作业的最大风险是人家改了自己不知道。

## 三、旧钱：阈值再平衡

### 目标配比

`rebalancer.calculate_target()` 直接使用基准权重。

### 资金口径

核心资金 = 总资产

### 触发阈值

| 条件                       | 阈值  |
|----------------------------|-------|
| 单类偏离（默认）           | > 5%  |
| 总偏离强制触发             | > 15% |
| trending_up / weak_up 放宽 | > 8%  |
| trending_down / chaos 收紧 | > 3%  |
| 忽略碎股偏差               | < 2%  |

regime 只选阈值松紧（门控残值），不触发额外的仓位动作。黄金、债券为受保护类型（`PROTECTED_TYPES`），下行市/硬拦截下不减。

卖出只出现在三种情况：阈值再平衡、半年基准对齐后的目标变更、极端熔断提示（见第七节，只提示不自动执行）。

### 执行流程（`--execute`，每周一 9:35 一个批次两件事）

1. **核心再平衡**：中性基准 → 对比持仓 → 核心 orders
2. **卫星仓动量调仓**：扫描行业 ETF 清单，动量关注池 ∩ 放量突破 → 卫星卖出/买入指令（见 [industry_momentum.md](./industry_momentum.md)）

全批次安全校验（任一失败整批中止）：买入总额 ≤ 可用资金 + 卖出回款；每笔卖出股数 ≤ 实际持仓；卫星买入 ≤ 10% 预算。

执行顺序（核心优先）：卫星卖 → 核心卖 → 核心买 → 卫星买，妙想市价单（需开盘后）；执行后重拉持仓复核并输出。

**妙想交易限制处理**：1 开头深市 ETF/LOF（如 159934、159938、159928）妙想模拟仓无法识别市场号（买/卖都拒绝，见 `docs/mx_skills/mx-moni.md`）。执行时自动跳过这类订单（`is_mx_untradable`），不调 API，在报告"需手动处理"小节列出，由人工登录妙想 App 手动操作。选股清单 `ETF_INDUSTRY_MAP` 优先用沪市等价标的，仅无替代或需保留卫星持仓监控时保留 1 开头条目。

## 四、新钱：节奏判断

增量资金是本策略相对基准来源方的真正优势。新钱环节**不考虑缺口**——入金后各资产自然欠配，缺口 = 目标权重 x 入金后总资产 - 实际市值，入金后按基准权重自行补入即可（缺口口径的指令由旧钱再平衡处理）。新钱环节唯一的问题是**补入节奏**：

1. **主规则（右侧纪律）**：欠配资产站上 MA20 → 可正常补；MA20 下方且趋势向下 → 不急，分批或等站回 MA20。这是把体系的右侧纪律应用到增量资金的进场节奏上，避免"见缺就补"变成左侧接刀。
2. **估值修正**：估值锚对准跟踪指数自身（中证官网当前 PE/股息率，映射见 `config.py:TRACKED_INDEX`，指数代码经官网实测核对）。**不做逐指数历史分位**（2026-09 决策：官网无历史文件，自建积累冷启动约一年不现实；逐指数加速与趋势主规则、全局便宜档高度重叠，收益不抵维护成本），未映射标的回退申万行业 PE 分位，全市场仅作兜底——不混锚，PE 跨标的不可比。红利类（股息策略，`DIVIDEND_STYLE_CODES`）以股息率为主锚：股息率 − 10Y 国债利差 ≥1.5pt 且企稳 → 加速（利差为跨资产口径，零历史依赖）。估值只做加速不做减速——减速即本地择时，与"只抄基准"冲突。
3. **全局节奏（双向极端档，回答"要不要整体先等等 / 要不要整体加速"）**：常态不表态——按比例并入即默认答案，权益/现金整体配比观点归基准（同一估值观点不重复计价）。暂缓档：全市场 PE 分位 ≥90%（与卖出警示同阈值），或风险溢价（1/全市场PE − 10Y 国债）自身近 5 年分位 ≤10%（跨资产口径的独立确认）→ 整笔新钱留在场外等分位回落或分批。便宜档：全市场 PE 分位 ≤30% → 整体偏便宜，可适当加速并入（不必等回调）——逐指数估值加速取消后，"系统性便宜"由这一档接管（全市场序列近 5 年已具备，零额外积累）。触发时逐标的表内 🟢 仅为相对优先级。
4. **边界**：资产逻辑长期恶化导致的"永远性欠配"不归本层处理——在对齐时下调其目标权重，欠配自然消失。新钱表只做弱势提示，不做基本面判断。
5. **执行边界**：仅建议、不自动执行、无金额参数。周报固定输出"新钱投放参考"（全局节奏 + 逐标的节奏），到账后照表在**真实账户**人工操作——妙想模拟仓只跑旧钱再平衡与新钱无关。`--execute` 批次只含旧钱再平衡与卫星调仓。
