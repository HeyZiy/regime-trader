# 网格接网试点（Grid Pilot）— 研究契约与规格

> 状态：**规格冻结（2026-09-22，经 grill 流式问答确认）。回测未开始，零生产预算，不自动下单，不接入现有策略。**
> 信号模板按"每个核心仓成份一份"设计：A500 为试点标的，510300 为主回测代理。原始网格方法参考 [cycle_strategy.md](./cycle_strategy.md) 所引的 E大网格三部曲。

## 一、定位

- **核心仓永不动**。网格层 = 专用现金 + 向下买入阶梯（模式一·下阶梯变体）：价格每跌一网，用现金多买超过核心仓规定部分；反弹按"上一网买入价"逐网卖出还网。
- 本层是**纯增强层**：吃"跌下去再回来"的波动；组合的熊市回撤保护不在本层职责内。
- 定性：试点 + 信号库验证。全部网格资金 ≈ 总仓位 10–14%，组合增强期望 0.5–1.0%/年，最大亏损由 cap 封顶。

## 二、结构参数（冻结）

| 参数 | 值 | 备注 |
|---|---|---|
| 每网金额 | 该持仓市值 × 10% | A500 即 1 手 |
| cap（最大超买网数） | 2 网 | 回测扫描 1/2/3 |
| 网距 | 5% | 回测仅扫描 3/5/8 三档 |
| 买入阶梯 | 参考价 −5%、−10%（逐网向下） | 参考价 = 开关转"开"当日收盘价；重启时重置阶梯 |
| 卖出价 | 上一网买入价 | 反弹逐网还网，E大 1.0 规则 |
| 现金预算 | 持仓市值 × 20% | 专用缓冲池，单独记账，与备用金隔离 |
| 最小交易单位 | 100 份 | 每手按整数手执行，现金不足一网则该网跳过 |

## 三、开关信号（冻结，日级收盘口径）

三道闸 + 确认期 + 硬风控。信号只用 T 日收盘及以前数据，T+1 执行。

| 闸 | 定义 | 允许条件 | 关闭条件 |
|---|---|---|---|
| 1 估值否决（共享仪表盘） | 标的指数 PE 十年分位 | ≤ 80% | > 80%：禁止新开网；已接网只还网不接网，收尾后停止 |
| 2 趋势强度 | ADX(14) | < 25 | > 30；25–30 之间保持原状态 |
| 3 波动收敛 | 布林带宽(20) 的 500 日分位 | < 30% | 带宽急扩且收盘破上轨 |
| 硬风控（最高优先级） | 收盘 < MA60，或 < 近 60 日最低收盘 × 0.97 | — | **网格层全部清仓（含未还网手数），核心不动** |

- **双确认**：闸 2 与闸 3 同时允许才算允许。
- **确认期**：状态转换需连续 3 个交易日满足（回测扫描 3/5 两档）。
- 关闸（闸 2/3 关闭）语义：不接新网，已接网继续等反弹还网，还完即停。只有硬风控才强平。

## 四、回测方案（冻结）

- **主回测**：510300，2013-01-01 起，真实 ETF 价格，前复权口径记录。
- **交叉验证**：中证A500 指数回溯历史（2005 起，基日 2004-12-31；假设无跟踪误差，结论仅作参考）。
- **四组对照**：always-on 网格 / 带开关网格 / 买入持有 / 空仓。带开关版必须相对 always-on 证明开关有增量。
- **成本**：佣金免 5（已确认）、滑点 1–2bp、T+1 成交（信号次日开盘价成交，冻结）。
- **扫描范围**：网距 {3,5,8}% × cap {1,2,3}，共 9 组；确认期 {3,5} 两档。其余参数一律不扫。
- **指标**：年化、最大回撤、Calmar、最坏月、开关切换次数/年、每网平均净利（扣费后）、网格资金占用率。

## 五、验收（冻结）

- **安全硬门槛（不可豁免）**：
  1. 2018、2022 两段单边熊中，带开关网格回撤 ≤ 买入持有；
  2. 最坏单月回撤 ≤ always-on 网格；
  3. 无未来函数（信号仅用 T 日收盘数据，代码审查确认）；
  4. 开关切换 ≤ 8 次/年。
- **表现软判定**：Calmar / 年化方向性优于 always-on 与买入持有即可，不设百分比门槛（29% 与 31% 无区别，方向与分段一致性优先）。
- 达不到硬门槛 → 回炉，不降标准上线。

## 六、试点与放大（冻结）

- **不设独立模拟期**：网格层金额极小，试点前 3 个月即执行验证期——只考核台账完整性与成交一致率（≥ 95%），不考核收益。
- **放大三条件**（同时满足）：① 安全硬门槛全过；② 试点 6 个月执行无重大事故；③ 带开关 Calmar 方向稳定优于 always-on。
- 满足后：网格层预算提至 15–20%，或扩展第二持仓（核心仓成份中年化波动 ≥25%、日成交 ≥5000 万者优先，低波动红利类不适合）。
