# 参数敏感性与过拟合风险说明

> 目的：验证 §4 回测报告的"改进版优于基准"结论不是参数挑选或单段行情的产物。采用四种独立检验：单模块消融、参数扰动、开关组合、子区间+剔除极端段。
> 全部数据来自 `research_out/output/`（ablation.csv / sensitivity.csv / robustness.csv），可一键复现（`python run_backtest.py all`）。

## 1. 消融实验：模块贡献不可加，存在强交互

| 配置 | 累计收益 | CAGR | MDD | 夏普 | 敞口 |
|---|---|---|---|---|---|
| 基准（全关） | −55.4% | −6.82% | −62.8% | −0.17 | 27.0% |
| 仅 B1 延伸止盈 | −59.4% | −7.58% | −64.0% | −0.21 | 27.0% |
| 仅 A1 仓位档位 | −65.4% | −8.86% | −66.6% | −0.29 | 26.0% |
| 仅 A2 快速通道 | −55.4% | −6.82% | −62.7% | −0.17 | 27.1% |
| 仅 C1 ATR 过滤 | −40.4% | −4.43% | −59.0% | −0.09 | 25.1% |
| 仅 D1 方向门 | −33.6% | −3.52% | −57.4% | −0.05 | 24.6% |
| **全组合（改进版）** | **−5.4%** | **−0.48%** | **−43.7%** | **+0.06** | 19.6% |
| 仅信号门 C1+D1 | −21.1% | −2.05% | −50.2% | −0.00 | 22.1% |
| 全组合−A2 | −7.5% | −0.68% | −44.4% | +0.05 | 19.6% |

**发现与含义：**
- 稳健的独立贡献者是信号质量门 C1（+2.4pp）与 D1（+3.3pp）。
- **A1、B1 单独开反而恶化**：仓位档位单独用会在反弹初期压低敞口、延伸止盈单独用会过早砍掉趋势单——它们的价值依赖与信号门组合（信号门先提高入场质量，仓位/止盈模块再在更好的持仓集上发挥作用）。
- A2 单独开几乎无效（触发日太少），全组合内贡献约 +2.1pp（no_a2 对比）。
- **工程结论：吸收必须按全组合配置落地；任何"只挑一个模块"的裁剪都可能劣化。** 这一条已写入交接文档的配置建议。

## 2. 参数扰动：全部档位优于基准，方向一致

对五个关键参数各扫 3–4 档（其余保持默认），共 15 个扰动场景 + 2 个组合场景：

| 参数 | 档位 → CAGR%（MDD%） |
|---|---|
| ext_stk_thr（B1 延伸阈值） | 6% → −2.04（−49.5）｜ 8% → +0.33（−38.9）｜ **10% 默认 → −0.48（−43.7）**｜ 12% → +0.36（−38.3） |
| atr_exp_thr（C1 扩张线） | 1.2 → +1.70（−39.8）｜ **1.3 默认 → −0.48（−43.7）**｜ 1.5 → −2.47（−53.3） |
| cap_top（A1 顶部档） | 20% → +0.33（−37.9）｜ **30% 默认 → −0.48（−43.7）**｜ 40% → −0.64（−45.3） |
| panic_thr（A2 恐慌线） | −3.5% → −0.48（−43.7）｜ **−4.0% 默认 → −0.48（−43.7）**｜ −5.0% → −0.68（−44.4） |
| ext_idx_thr（A1 指数延伸线） | 3.5% → −0.15（−40.2）｜ **4.5% 默认 → −0.48（−43.7）**｜ 6.0% → −4.53（−54.7） |

- 扰动场景 CAGR 区间 [−4.53%, +1.70%]，**全部 17 个场景优于基准 −6.82%**；MDD 全部收窄。
- 默认配置不是敏感性曲面峰值（峰值为 atr_exp_thr=1.2 的 +1.70%）。刻意不用峰值作为推荐：单点最优大概率是噪声选择；默认配置取的是"参数邻域平台 + 机制可解释"的位置。若实盘启用，建议在交接文档约定的复核周期用滚动窗口重估阈值，而非一次性锁死峰值。

## 3. 子区间 + 剔除极端行情

| 区间 | 基准累计 | 改进累计 | 差值 | 基准 MDD | 改进 MDD |
|---|---|---|---|---|---|
| 2015-2018（泡沫顶+熊市+磨底） | −39.9% | −6.7% | **+33.3pp** | −49.3% | −37.6% |
| 2019-2022（反弹+结构牛+回落） | +4.6% | +25.9% | **+21.3pp** | −39.0% | −29.1% |
| 2023-2026（阴跌+924脉冲+震荡） | −29.1% | −19.5% | **+9.6pp** | −34.1% | −28.5% |
| 全区间剔除 2024-09-13~10-15 | −55.4% | −5.4% | **+50.0pp** | −62.7% | −43.7% |

- 三个子区间方向全部一致（+33 / +21 / +10pp）。
- 剔除 2024 年 9-10 月极端段后，两臂结果与全区间几乎重合（−55.4/−5.4 vs 全区间同值）——**改善不是由 924 脉冲贡献的**（A2 快速通道在该段的贡献有限，主贡献是全期性的敞口与入场质量控制）。

## 4. 过拟合风险评估（如实声明）

| 风险源 | 评估 | 缓解 |
|---|---|---|
| 参数挑选 | 低——默认值非峰值，17 个扰动场景全优于基准 | 敏感性表全量公开；建议滚动复核而非锁死 |
| 单段行情依赖 | 低——三子区间+剔除极端段方向一致 | 见 §3 |
| 模块裁剪 | **高**——A1/B1 单开有害 | 交接文档强制全组合配置，消融表留档 |
| 池构造偏差 | 中——存续偏差（现任成分回测历史）池内选股宽度有限 | 对两臂对称，不改变方向性结论；已在限制清单声明 |
| 复权口径 | 低——qfq 均线 + pctChg 涨跌停容差法，除权日个别误判两臂对称 | 台账抽查 + 两臂同口径 |
| 多重比较 | 中——本轮共运行约 30 个场景，存在"挑好看数字"的统计风险 | 结论只基于全组合 vs 基准的单一主对比；敏感性/消融仅用于稳健性论证，不用于另选更优配置 |

**总体判断：**"改进版优于基准"这一结论在四种独立检验下方向一致，过拟合风险可控；但"改进版绝对收益转正"不成立，不应基于本报告做出盈利预期。
