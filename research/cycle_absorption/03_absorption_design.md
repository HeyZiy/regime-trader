# 吸收改进设计文档 — Cycle → Trend 的组件转译与落地

> 上游：《Cycle 策略诊断报告》（01，美股假设逐条判定）；现状：《Trend 策略现状梳理》（02）。
> 本文档回答三个问题：**吸收什么、怎么改造、为什么放弃**。每个吸收项给出精确的可计算定义（回测引擎按此实现），每条诊断结论与本文档的处置项一一对应（对应关系见 §5 追踪表）。

---

## 1. 设计原则

1. **T+1 收盘口径内运行**：所有吸收组件只依赖日线收盘后可计算的字段（OHLCV、换手率、涨跌幅），与 Trend"盘后买入申报、14:45 尾盘卖出"的执行时序兼容。盘中组件一律不做（诊断 C1）。
2. **旁路不改语义**：gate 五态判定、信号 1/2 触发条件、既有卖出规则的语义一字不动；吸收组件以"消费 gate 输出 → 输出附加约束"的方式叠加（02 文档接入点 P1–P5）。
3. **全开关可归因**：每个吸收项独立开关 + 独立参数，支持消融实验（逐项加/减看边际贡献）与参数敏感性分析。
4. **弃用要写理由**：不符合 T+1/涨跌停/资金规模约束的组件明确弃用并记录，不做半吊子转译。

## 2. 吸收总览：改什么、为什么是它

Trend 现有体系的三个真实缺口（Cycle 有对应解法）：

| Trend 缺口 | Cycle 对应组件 | 吸收项 |
|---|---|---|
| 环境过滤是二值开关：只回答"能不能开仓"，无法表达"该开多大程度的总敞口" | 循环阶段仓位基调（底部≤4成/主升6–10成/顶部≤3成/下跌≤1成） | **A1 指数循环四档定位 → 组合仓位上限** |
| 止盈只有被动移动止盈（回撤 10%）+16 日到期：利润回吐深，趋势末段加速段没有主动落袋动作 | 衰竭延伸计数（第 2 次延伸卖 1/3–1/2、第 3 次清大部分） | **B1 个股延伸计数分批止盈** |
| V 型底重入慢：gate 要等 MA5>MA10>MA20 多头排列，2019-01/2020-04/2024-09 这类 V 反中放行滞后数周 | Reversal Extension 恐慌底识别 + 底部循环 4 成仓基调 | **A2 恐慌底登记 + 收复 MA10 快速通道（右侧）** |
| 信号无波动率状态感知：扩张日追买易吃回撤 | ATR 收缩/扩张语言 | **C1 ATR 扩张过滤** |
| 信号质量门缺均线方向维度 | Crossback 前置条件"均线走平或向上" | **D1 MA5 方向门** |

**不吸收买点侧的突破体系**（Wedge Pop / Base n' Break / Reversal 试仓）：执行制度不兼容（诊断 A2/A4）+ 与 Trend 盘后申报纪律冲突 + 小资金摩擦成本下追突破期望值劣化。Trend 的缩量回踩买点与 Cycle 的 EMA Crossback 同构且已 A 股化，保留。

## 3. 吸收项精确定义

### A1 指数循环四档定位（cycle_stage）

**输入**：上证指数日线（与 gate 同源）；**输出**：`cap_pct ∈ {0, 30%, 40%, 100%}` + 阶段标签。

判定顺序（每日收盘后）：

```
① 恐慌登记状态激活（见 A2）        → stage=bottom,  cap=40%
② gate 判定为禁开仓状态             → cap=0%（维持 Trend 原语义，不动）
③ 指数顶部延伸激活（见下）          → stage=top,    cap=30%
④ 其余（trending_up/weak_up）      → stage=main,   cap=100%
```

**指数顶部延伸**（B1/B2 诊断的指数侧改造）：`bias_idx_ma10 = (close−MA10)/MA10×100 ≥ ext_idx_thr`（默认 4.5%，敏感性 {3.5,4.5,6}%）。为避免单日噪声反复触发，延伸激活后保持激活直到 bias 回落到 `ext_idx_thr × 0.5` 以下（滞回）。激活期间：新开仓受 cap=30% 约束；已持仓不强制减仓（卖出仍由个股规则驱动，避免与 B1 重复调节）。

**依据**：Kell §03 仓位基调（C4 判定✅）+ §09"指数参照沪深300"的 A 股转译；阈值按诊断 B1 重新校准——A 股指数对 MA10 偏离 4–6% 的频率远高于 QQQ，取 4.5% 为 2015–2025 上证日收益波动分位对应值，敏感性回测覆盖。

### A2 恐慌底登记 + 收复快速通道（panic_fastpath）

**输入**：上证指数日线。两个条件全部满足时记一次**恐慌底事件**（当日）：

```
P1 偏离： bias_idx_ma10 ≤ −panic_thr      （默认 −4.0%，敏感性 {−3.5,−4,−5}%）
P2 恐慌量能+反转K线：当日量 ≥ 1.5 × 前20日均量 且（收阳 或 长下影：min(open,close)−low ≥ 2×|close−open|）
```

**快速通道语义**（转译 Kell"试仓"为右侧放行，诊断 C5）：恐慌事件登记后 `fp_window=10` 个交易日内，若某日 `close ≥ MA10 且 当日涨跌幅>0`，且当日 gate 判定仍为禁开仓（chaos/trending_down/sideways）→ 当日按 weak_up 放行开仓，`cap=40%`（底部循环基调），快速通道仅当日有效（次日重新判定）。若窗口内指数又创恐慌事件以来新低，登记清零重计。

**为什么是右侧**：T+1 下当日买入不可止损（诊断 A1/C5）；恐慌日直接试仓的期望受隔夜跳空支配。收复 MA10 + 阳线确认把介入点移到右侧，牺牲 1–3 天的底部利润换取"买入次日起就有 MA10 止损参照"。2024-09-24 行情是设计靶场：gate 多头排列在 10 月中旬才成立，快速通道在 9 月末收复 MA10 即放行。

### B1 个股延伸计数分批止盈（exhaustion_overlay）

**输入**：个股日线（持仓期间）；**输出**：与 sell_rules 同语义的 `reduce_half / clear` 动作。

```
延伸日： bias_ma10 = (close−MA10)/MA10×100 ≥ ext_stk_thr   （默认 10%，敏感性 {6,8,10,12}%）
延伸事件(e1,e2,…)：连续延伸日合并为一次事件；bias 回落 < ext_reset_thr（默认 4%）后再次延伸才计新事件
第 1 次事件：不动（正常强势段，让移动止盈兜底）
第 2 次事件出现时：输出 reduce_half（卖 1/3–1/2 → 引擎取 50%，与 Trend 减半语义一致）
第 3 次事件出现时：输出 clear（Kell"第 3 次延伸清掉大部分"）
```

计数器**持仓级**（入场日起算），与移动止盈 peak 同生命周期；平仓后计数器销毁。与既有规则同日触发时取最强动作（clear > reduce_half > 无动作），符合 sell_rules 合并语义（02 文档 P3）。

**依据**：Kell §02 阶段 5 + §07 触发器 1/2；阈值按诊断 B2 放宽（美股 8% → A 股默认 10%），且用回测选稳态值。**注意与 Trend 现有约束的相容性**：信号入场时 MA20 乖离<15%、V7 60 日涨幅<80% 已挡掉大部分深延伸入场，延伸计数只在持仓演化中起作用，二者职责不同不冲突。

### C1 ATR 扩张过滤（atr_filter）

```
TR = max(high−low, |high−prev_close|, |low−prev_close|)
ATR5, ATR20 = TR 的 5/20 日简单均值
过滤：对候选信号（信号1/信号2确认日），若 ATR5 > 1.3 × ATR20 → 当日信号剔除（不触发、不评分）
收缩（ATR5 < ATR20）不加权不加分——保持"只剔除、不改评分"的最小侵入
```

依据：Kell §01/§04 条件 4（B4 判定✅）；扩张=正在失控的波动，A 股对应一字开/巨振追高风险，T+1 下次日不可撤。参数 `atr_exp_thr` 默认 1.3，敏感性 {1.2, 1.3, 1.5}。

### D1 MA5 方向门（slope_gate）

```
对信号 1 / 信号 2 确认日：要求 MA5(t) ≥ MA5(t−1)（走平或向上）
```

依据：Kell Crossback 清单"10/20 EMA 走平或向上（不是向下压着价格）"；Trend 信号 1 已有"过去 5 天 3 天站上 MA5"（首次回踩近似），缺方向维度。零参数、零新数据，成本最低的质量门。

## 4. 弃用清单（逐条理由，对应诊断编号）

| 弃用组件 | 诊断 | 理由 | Trend 内的替代/覆盖 |
|---|---|---|---|
| Wedge Pop / Base n' Break 突破买入 + buy stop 触发单 | A2、A4 | A 股无条件单基础设施；突破高开吞没低风险点；盘后收盘价申报纪律下"突破买入"无执行落点；1 万资金 0.1% 滑点+最低佣金对追价惩罚重 | 保留缩量回踩买点（与 Crossback 同构）；强势突破后的回踩即信号 1，机制上不漏趋势 |
| Reversal Extension 逆势试仓（半仓抄底） | A1、C5 | T+1 当日买入无法止损；与纪律红线 1 冲突 | 转译为 A2 右侧快速通道 |
| 下行阶段全部做空动作 | A3 | 账户只做多；融券不可用 | gate 禁开仓 + 收紧卖出已覆盖下行防御 |
| CANSLIM 基本面筛选 | B5 | 无数据管道；违反最小侵入 | 妙想选股截面 + V1–V9 负面清单承担准入职责 |
| 周线/月线结构判定层（20 周 EMA） | B6 | 日线框架内以 60 日结构近似已够；完整周线层复杂度不成比例 | V7（60 日低点涨幅>80% 否决）+ A1 指数定位 |
| 财报前减仓规则 | B7 | 无财报日历管道；V1 公告否决 + 16 日到期已覆盖风险窗口 | V1、到期上限 |
| 单笔风险 0.25–0.5% + 分批建仓 | A5 | Trend 已有同思想仓位公式（200 元亏损预算÷止损距离）；1 万资金下分批建仓手数取整损耗大 | 现有 position_size 机制 |
| 量能语言双阈值体系（1.5×/0.7× 20日均量） | B3 | 与 Trend 现有量比口径（5 日均量）职责重叠，两套阈值并存会互相干扰 | 现有量比阈值（除 A2 恐慌检测内部使用 1.5×20 日均量，属指数级新维度不冲突） |
| 卖出触发器 6/7（买入理由消失、负面预期跳空） | — | 不可量化（叙事性条件） | 移动止盈 + 第二卖点承接等价风险 |
| 3 触点趋势线、楔形等视觉形态 | C2 | 视觉判定无数据管道 | 不替代；延伸计数覆盖趋势末段的主要风险 |

## 6. 已知限制（诚实声明）

1. 股票池为"现任沪深300/中证500 成分 ∩ 2015 前上市主板"的**存续偏差池**（今日视角选池回测历史），对基准与改进版对称失真，不改变两者对比的方向性结论，但绝对收益水平偏乐观。
2. 板块走弱/主线退潮规则按规格自身的数据缺失语义 fail-open 跳过（两臂一致）。
3. 换手率、ST、停牌用 baostock 历史口径；涨跌停用 pctChg±9.5% 容差法，除权日附近可能个别误判（两臂对称）。
4. 回测资金 10 万元（损失预算 200 元/笔保持不变）以提高手数取整下的样本量；1 万元口径的粒度差异在交接文档说明。
