# Trend 策略现状梳理 — 代码结构、信号逻辑与可扩展接入点

> 依据：`trend_strategy.md`（策略规格）+ 文中引用的模块路径。本仓库**不包含** Trend 真实代码库（其位于用户交易机），本梳理按规格文档 1:1 重建基准逻辑用于回测对照，并给出吸收模块接回真实代码库的映射（见 `07_integration_patch.md`）。

## 1. 现有模块地图（规格文档引用路径）

```
src/
├── market_state/market_gate.py      # 大盘状态判定（五态，纯结构口径）
└── trend/
    ├── report.py                    # 日报主程序：LOSS_BUDGET / position_size 在此
    ├── veto_rules.py                # 负面清单 V1–V9（硬否决层）
    ├── sell_rules.py                # 卖出信号判定
    └── signal_detector*             # 买点信号 1/2/3 检测与评分
trend_sell.py                        # 14:45 尾盘自动执行（读妙想模拟仓下单）
data/position_exit_state.json        # 移动止盈 peak 落盘（每日 14:45 更新）
research/trend_bt/                   # 已有回测资产（T+1 确认买点证伪、移动止盈口径对比）
```

**关键工程事实**（影响吸收方式）：
- 执行时序固定：买入=信号日盘后 15:05–15:30 按收盘价申报；卖出=14:45 尾盘检测并自动下单。判定与定价同用收盘口径 → **所有 Cycle 吸收组件必须以"日线收盘后可计算"为约束**，任何盘中依赖都无法落地。
- `market_gate` 的五态判定是**纯结构口径**（MA5/MA10/MA20 相对位置+收盘关系），判定优先级 trending_down > trending_up > sideways > weak_up > chaos，被多处复用 → 吸收不能改它的判定语义，只能**在它旁边叠加旁路模块**。
- 卖出判定按"当前持仓重新判定"，系统不做已减仓阶段跟踪 → 延伸计数类组件必须**自带持仓级状态**（与移动止盈 peak 一样落盘或内存保持）。
- 负面清单分两段执行：行情类（V2/V3/V4/V6/V7/V9，纯本地）全池跑，外部数据类（V1/V5）惰性对候选跑，fail-open → 吸收组件若引入新数据依赖，必须遵守同一 fail-open 约定。
- 已有回测结论可复用："T+1 确认买"被证伪（配对差 -0.67pp）、"移动止盈 0.90"优于"MA10 止损"（+1.10% vs +0.32%）→ 吸收组件的验证必须以同一基准口径对照。

## 2. 信号与风控逻辑要点（基准回测的实现口径）

### 大盘门控（能否开仓）
| 状态 | 条件 | 开仓 | 持仓 |
|---|---|---|---|
| trending_down | MA5<MA10<MA20 且 收盘<MA10 | ❌ | 收紧卖出 |
| trending_up | MA5>MA10>MA20 且 收盘>MA10 | ✅ | 正常 |
| sideways | 收盘偏离 MA20 <1.5% | ❌ | 正常 |
| weak_up | 收盘>MA20 且非以上 | ✅ | 正常 |
| chaos | 收盘<MA20 乱序 | ❌ | 正常 |

收紧卖出（trending_down 专用）：量比阈值 2→1.5、阶段高点回撤 5%→3%、板块走弱 -2%→-1%。

### 选股与准入（当日名单=妙想截面，本回测用池内条件近似）
市值 30–500 亿 / 均线多头 / 换手 3–12% / MA20 乖离<15% / 距 60 日低点<80% / 排除创业科创北交所与 ST。
跳过规则：连续 2 天破 MA10；放量长阴（跌≥5%+量比≥2+收盘<MA10）；情绪过热（5 日换手均值>5% 且 >20 日均值 2 倍）；流动性枯竭（5 日换手<1% 且无一日≥3%）。
负面清单行情类（本地可算）：V2 60 日涨幅>100%；V3 20 日换手均值>12%；V4 20 日内单日跌>7% ≥2 次；V6 20 日涨跌停≥3 天；V7 距 60 日低点涨幅>80%；V9 20 日收益 std>5%。V1/V5 为外部数据类，回测按规格的 fail-open 语义跳过（V1 的公告否决无历史管道；V5 资金流无历史管道）。

### 买点信号（盘后收盘判定，信号日收盘价申报买入）
- **信号 1 缩量回踩 MA5**（最优，评分 50–95）：守住 MA5（≥×0.995）、量<5日均量×1.1、bias_ma5∈(−1.5%,3.5%)、日内承接（close_position>0.4 且下影>10%）、换手>3%、非情绪/中期过热（⑥⑥b）、前期 5 天 3 天站上 MA5、涨跌幅∈(−5%,7%)、当日真回踩（收阴或盘中触及 MA5×1.005）。
- **信号 2 回踩 MA10**（次优，评分 30–85，需次日弱转强确认→确认日执行）：跌破 MA5 前提 + 触及 MA10 且收盘守住 + 缩量 + 承接 + 换手 + 过热条件。**回测按确认日收盘执行**（规格明确信号 2 例外）。
- **信号 3** 是观察信号非买点，不产生成交。

### 卖出（14:45≈收盘判定，先到先出）
- 第一卖点（减半，其一）：量比≥2 且收<MA5；高位长阴吞没（前阳被阴吞+跌≥3%+高位）；收盘<近 20 日最高收盘×0.95；板块走弱（数据缺失跳过→回测跳过）。
- 主干退出（清仓，先到先出）：移动止盈 max(持仓期最高收盘,入场价)×0.90，peak 只升不降；持满 16 个交易日到期。
- 第二卖点（清仓，其一）：量比≥2 且收<MA10；收盘<近 20 日最低收盘；板块跌幅≤-3%（跳过）。
- 止盈保护（减半）：盈利≥15% 且放量滞涨。
- trending_down 切收紧版；极端止损由用户盘中手动（不在系统内）。

### 仓位与账户纪律
单笔亏损限额 200 元（1 万元本金 ×2%）；仓位上限=200÷止损距离（止损参考 MA10、距离下限 3%）；100 股一手取整；固定额度不追加，回撤 20% 暂停 1 个月（回测不复现该暂停规则，作为已知差异记录）。

## 3. 可扩展接入点（吸收模块的落点）

| 接入点 | 位置 | 方式 |
|---|---|---|
| P1 环境过滤旁路 | `market_gate.py` 判定输出之后 | gate 五态保持不变；新增 `cycle_stage` 模块消费 gate 结果 + 指数结构，输出四档仓位上限；`report.py` 开仓放行处乘上限系数 |
| P2 gate 快速通道 | `market_gate.py` 之外（旁路） | 恐慌底检测器监听指数日线，登记后若干日内若收盘收复 MA10，对 chaos/trending_down 的禁开仓给一次"按 weak_up 放行"的旁路（可开关，默认开，仓位上限压 4 成） |
| P3 卖出信号叠加 | `sell_rules.py` 判定结果合并处 | 新增持仓级 `ExhaustionTracker`（延伸计数），输出"减半/清仓"动作，与现有规则取最强动作 |
| P4 信号质量门 | `signal_detector` 触发之后、评分之前 | ATR 扩张过滤（ATR5/ATR20>1.3 剔除）+ MA5 方向门（MA5 走平向上），只做剔除不改触发与评分 |
| P5 配置开关 | 各模块 config | 全部吸收组件带独立开关与参数，`cycle_overlay.enabled=false` 时行为与基准逐 bit 一致 |

**最小侵入原则**：不改动 gate 判定语义、不改信号触发条件本体、不改既有卖出规则；吸收组件全部以"旁路模块 + 合并点"方式接入，均可独立开关、独立回测归因（消融实验见回测报告）。
