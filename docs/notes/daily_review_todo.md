  - ⚠️ 若按 09-09 的静态「开口小优先」落地，趋势段将系统性亏约 9pp。**这条优先级高于任何池子层调整**
  - 做法：不做门槛，做**排序取端** —— trending_up 取开口大端，sideways/下跌段取开口小端
  - 前置依赖：**必须先修 P0「市场环境跑在 T-1」**，否则变盘日 regime 判错会把偏向搞反，负负得正变双倍亏损
  - 阈值待定：先扩到 2-3 个不重叠的 trending_up 窗口确认符号稳定性，再谈切哪一分位
- [ ] **regime gate 职责扩展**：从「决定能否开仓」扩展为「决定域内往哪端偏」
  - 依据：域条件在趋势段超额 -2.6~-5.5pp，但域内 Q4 能到 +10.97%（超国证2000 +8.87%）→ **域有 alpha，但只在强动量端**
  - 现有 regime gate 只做 chaos/非 chaos 二值判断，浪费了它真正该干的活
