## 2026-09-10（周四）· 无日报日：多截面域检验（结论推翻 09-09 两项）

**三条判决：**

1. **域条件在趋势段跑输更多，不是横盘段的锅。** 趋势段超额 -2.6~-5.5pp，横盘段仅 -0.35pp。09-09「方向不全错、只是横盘段不利」的辩护不成立。4/16 胜率 67% 但中位跑输 2.6pp——**赚了 beta 的小头，丢了大头**。
2. **域内 alpha 存在，但集中在强动量端。** 4/16 域内开口度 Q4 中位 **+10.97%，超过国证 2000 +8.87%**。域不是没好票，是平均被稀释。→ 域内必须做动量排序取强。
3. **freshness 方向随环境翻转（推翻 09-09 结论）。** 开口度 Q1−Q4：趋势段 **-9.24 / -7.57 / -9.42pp**（开口越大越好，Spearman +0.12~+0.18），横盘段 **+8.47pp**（开口越小越好，Spearman -0.279）。**若按 09-09 的结论落地静态「开口小优先」门槛，在趋势段会系统性亏约 9pp。**

**稳定成立的两条（4/4 期方向一致，可固化）：**
- 换手 >12% 是毒源：中位差 -0.18 / -3.80 / -3.65 / -6.24pp → **V3 前移确认，趋势段也不误杀**
- PE<0 组占优：中位差 +4.24 / +3.90 / +0.59 / +3.44pp → **PE 门全撤确认，不是题材市特性**

**操作含义**：freshness 不能做成静态门，须由 regime 切换方向（trending_up 取开口大端，sideways 取开口小端）。**regime gate 的职责应从「决定能否开仓」扩展为「决定域内往哪端偏」**——而当前 regime 判定跑在 T-1 数据上（P0 未修），变盘日会把偏向搞反，**修 P0 是做 regime 自适应的前置条件**。

### 规则层：5 个漏洞让妖股被识别成趋势股

1. **代码里没有「底部」概念。** 策略文档开篇写「趋势交易（**底部偏右进场**）」，但所有条件都是相对自身近期均线/涨幅（守住 MA5、MA20 乖离<15%、近20日涨幅<80%），**没有一条是相对于本轮行情起点的**。所以选出的是「顶部偏右」。
2. **过热判定用「相对自身」，长期高换手永不过热。** `近5日换手>5% AND >近20日×2`：风范近5日 16.69%、近20日 16.90%，需 >33.8% 才触发。**连续 20 天换手 17% 的妖股，因为"一直都很热"，反被判为"不过热"。** 这个 AND 本意防低基数误杀，副作用是投机股永久免疫。
3. **涨幅判定用「端点」，忽略路径。** `近20日涨幅<80%`：风范 T−20 起点 6.51 已在半山腰，算出仅 +26.7%（实际从 4.50 起 +83.3%，从 4.14 起 +99%）。**行情超 20 日后该指标失效**——等于用最后一公里的坡度判断整座山的高度。
4. **波动率维度完全缺失。** 全是幅度指标（近3日涨幅<18%、近5日涨幅<30%、近3日振幅<15%），没有标准差/ATR。风范近三日 −4.30%/+4.74%/−1.79%，净涨幅 −1.55% 稳过。净涨幅衡量不了路径风险。
5. **评分只评价「这个点」，不评价「这只票」。** 六个维度（乖离 25 / 量比 20 / 涨跌幅 15 / 换手 15 / 日内承接 15 / 站上MA5天数 10）全在问「这根 K 线形态好不好」，**没有一个问「这只票还能不能买」**——涨了 103%、换手 17%、主力流出 3.82 亿、PE 为负、公司自曝炒作，一概不问。**形态识别披着交易决策的外衣，是事故根源。**

### 决策层：3 个问题

1. **「生成信号」被当成任务，而不是「做正确决策」。** sideways 明令禁止开仓，程序照样输出两只票并给完整操作计划。没有好机会时正确输出是「今天没有值得做的交易」；输出 56 分和 44 分的信号，是在**制造行动压力**。
2. **日报框架预设「每天应该有信号」**（「共发现 2 个技术信号」）。趋势交易的本质是**大部分时间空仓**。
3. **铁律只有「不碰 ST、低流动性」**，对更常见的陷阱一条都没有：游资爆炒股、公司发风险提示、PE 为负、主力持续流出。
